Jeanette Waters — Puppet Show Pilot
Client-facing preview site for a 90-day AI puppet show pilot: daycare educational video content produced for Let God Help Resources (Jeanette Waters, Bear, DE).
What this is
A single-page preview site Jeanette can click through to review pilot deliverables:
Episodes — preview + approve/request-changes for each puppet episode
Daycare Map — target daycares in the Bear, DE distribution area
Digital Footprint — projected reach trajectory over the 90-day pilot
ROI Goals — pilot deliverable targets (episodes, daycares reached, live events)
Status
🟡 Pilot preview — pre-contract. Episode content is placeholder pending finalized scripts.
Stack
Static HTML/CSS/JS, no build step. Deployed via Cloudflare Pages, connected directly to this repo.
Deploy
Push to main → Cloudflare Pages auto-builds → live at the Pages project URL.
No environment variables or build command required.
